# Repository instructions

## GitHub contribution rules

- Before editing or committing, inspect `git status`, the current branch, configured remotes, and existing changes. Preserve unrelated work.
- Use the repository's existing verified Git identity. Never change local or global Git identity automatically.
- Commit each meaningful completed development task with a clear, conventional message. Do not create artificial commits or unnecessary changes to inflate contributions.
- Push completed commits to the repository's default branch when appropriate. Preserve remote history; never force-push, rewrite history, or overwrite existing work without explicit permission.
- Before committing, review the staged diff and confirm no credentials, secrets, or unrelated files are included.
- After committing and pushing, verify the commit author, branch, commit hash, and push result. Report any authentication, conflict, or permission blocker accurately.
